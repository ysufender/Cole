
    Usage:
        jaslc <input_file> [options]

    Options:
        --help, -h                  : Print this help message.
        --version, -v               : Print version info

        --output, -o   <path>       : Output file name.

        --working, -w  <path>       : Set working directory
        --max-err, -m  <count>      : Set max error count before terminating the compilation. Defaults to 10
        --include, -I  <path>       : Add <path> to the searchpath of the compiler. Can be relative or absolute.
                                      Included path will also be used by the backend.

        --parse-only                : Parse the project, do not compile
        --typecheck-only            : Typecheck the project, do not compile
        --resolve-only              : Resolve the project, do not compile

        --allow-recursion           : Allow recursion, for some reason. Why don't you just iterate?

        --link, -l     <lib>        : Link <lib>, found from the searchpath, to the final
                                      output.
        --link-dir, -L <path>       : Add <path> to library searchpath.

        --optimize, -O <level>      : Specify optimization level. Available levels are:
                                          g, 0, 1, 2, 3
